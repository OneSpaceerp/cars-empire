5. API Contract
Base URL: https://api.carsempire.example/v1 (placeholder). JSON over HTTPS. All mutation endpoints must support idempotency where a duplicate request could create money, inventory, a booking or a voucher.
5.1 Conventions
Authorization: Bearer <access_token>
Content-Type: application/json
Idempotency-Key: <uuid>
X-Request-Id: <uuid>
Accept-Language: en-EG or ar-EG
